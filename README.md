# ✈️ 國際旅遊外幣購物預算精算機

把國外當地的外幣標價換算成實際台幣成本（含刷卡手續費與退稅），再跟蝦皮台灣的市場價格比較，自動告訴你這件該在國外買還是回台灣在蝦皮買。

## 專案結構

```
travel_budget/
├── app.py            # 主程式（Streamlit）
├── requirements.txt  # 相依套件
└── README.md
```

## 安裝與執行

```bash
pip install -r requirements.txt
streamlit run app.py
```

## app.py 模組架構

| 區塊 | 函式 | 說明 |
|---|---|---|
| 匯率 | `fetch_bot_rates()` / `parse_bot_csv()` | 台銀 CSV：處理 BOM／Big5 編碼，用「本行賣出」標記定位現金賣出欄（因為台銀 CSV 的欄名有重複）；沒有現金報價時改用即期賣出；從檔名取出牌告時間 |
| 蝦皮 | `fetch_shopee_items()` | 五道防護：① `st.cache_data(ttl=600)` ② 隨機延遲 1–2 秒 ③ Session + 完整標頭 ④ 選填 Cookie（自動帶 CSRF） ⑤ 永不拋出例外 |
| 備援 | `generate_mock_items()` | 結構與真實資料一致；以關鍵字當亂數種子，所以同一個關鍵字每次產生的資料都相同，方便錄影 |
| 分析 | `calc_overseas_cost()` / `decision_advice()` / `remove_outliers_iqr()` | 成本公式、決策標籤、極端值過濾 |
| 介面 | `render_sidebar()` / `render_charts()` / `render_table()` / `main()` | 側邊欄、Plotly 圖表、明細表與 CSV 下載 |

## 計算公式

- 海外實際台幣成本 = 外幣標價 ×（1 − 退稅%）× 匯率 ×（1 + 手續費%）
- 價差比例 =（蝦皮中位數 − 海外成本）÷ 蝦皮中位數
  - 大於 20%：🔥 國外必買
  - 10–20%：👍 可以順手買
  - 0–10%：📦 直接蝦皮買
  - 小於 0：🚫 國外反而比較貴

## 降低被擋風險的設計

- **三種資料來源模式**：
  - 自動：先抓即時資料，失敗時自動改用備援資料
  - 僅離線備援：完全不連線，錄影時推薦使用
  - 匯入 JSON：用自己的瀏覽器在蝦皮搜尋後，存下回應內容再上傳
- **守門員**（`shopee_guard`）：
  - 節流：兩次請求至少間隔 6 秒
  - 限量：每小時最多 20 次
  - 斷路器：一旦被擋，30 分鐘內完全不再連線
- 快取命中時不會發出請求，也不會用掉每小時的額度。

## 注意事項

- 蝦皮 API 是非公開介面，常會回傳 403 或風控錯誤代碼。遇到時程式會自動切換到離線備援模式，畫面上也會顯示原因。
- Cookie 只會存在當次執行的記憶體裡，不會寫入任何檔案。請勿把含有 Cookie 的截圖公開。
- 請合理使用，避免短時間內大量查詢。
