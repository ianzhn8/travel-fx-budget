# 👕 國際旅遊外幣購物預算精算機｜UNIQLO × GU

**同一件 UNIQLO／GU，在台灣蝦皮買划算，還是去日本時直接買划算？**

這個 App 會把日本官網的日幣含稅價，換算成實際台幣成本（含匯率、刷卡手續費、退稅），再跟台灣蝦皮的市場價格比較，最後給出購買建議：

- 🔥 日本必買
- 👍 可以順手買
- 📦 直接蝦皮買
- 🚫 日本反而比較貴

支援的類別：長袖、短袖、外套、襯衫、長褲、短褲、配件。

## 畫面內容

- **關鍵指標**：台銀匯率、日本實際台幣成本、蝦皮最低價、蝦皮中位數價、最大價差
- **購買決策建議**：依價差比例自動判斷，並算出買 N 件總共省多少
- **日本官網每件商品 vs 蝦皮中位數**：依「日本買省多少」排序
- **蝦皮商品明細**：可以依台灣現貨或海外出貨篩選，也可以下載 CSV

## 專案結構

```
app.py        Streamlit 介面
catalog.py    品牌、類別設定與共用解析（只用標準庫）
collect.py    建立價格資料庫的工具（只用標準庫）
data/         資料庫快照（official_snapshot.csv、shopee_snapshot.csv）
raw/shopee/   放從瀏覽器存下的蝦皮 JSON（不會上傳到 GitHub）
```

## 建立資料庫

### 1. 日本官網：自動抓取

```bash
python collect.py official
```

### 2. 蝦皮：用自己的瀏覽器存下搜尋結果

1. 用瀏覽器打開蝦皮，搜尋例如 `UNIQLO 長袖上衣`。
2. 按 F12 → Network，在篩選框輸入 `search_items`，再按 F5 重新整理頁面。
3. 點那筆請求 → Response，全選複製，存成 `raw/shopee/UNIQLO_長袖.json`。
4. 其他類別照做，檔名規則都是 `品牌_類別.json`。

建議的搜尋字和檔名：

| 類別 | 蝦皮搜尋字（UNIQLO／GU 擇一） | 檔名 |
|---|---|---|
| 長袖 | 長袖上衣 | `UNIQLO_長袖.json` |
| 短袖 | 短袖T恤 | `UNIQLO_短袖.json` |
| 外套 | 外套 | `UNIQLO_外套.json` |
| 襯衫 | 襯衫 | `UNIQLO_襯衫.json` |
| 長褲 | 長褲 | `UNIQLO_長褲.json` |
| 短褲 | 短褲 | `UNIQLO_短褲.json` |
| 配件 | 配件 | `UNIQLO_配件.json` |

存好之後執行：

```bash
python collect.py shopee
```

### 3. 上傳資料庫

把 `data/` 裡的兩個 CSV 上傳到 GitHub。在網頁上用「Add file → Upload files」，放進 `data/` 資料夾即可。Streamlit Cloud 會自動重新部署。

- 同一天重複執行不會產生重複資料。
- 隔幾天再收集一次，資料會依日期累積，App 一律使用最新一天的資料。

## App 的資料來源模式

| 模式 | 日本價格 | 蝦皮價格 |
|---|---|---|
| 📦 資料庫快照（推薦） | 資料庫，沒有的話改即時查詢 | 資料庫 |
| 🌐 即時查詢 | 即時查詢，失敗的話改用資料庫 | 即時查詢，失敗的話改用資料庫 |
| 📂 匯入蝦皮 JSON | 同上 | 上傳的檔案 |
| 🛟 離線模擬 | 同上 | 模擬資料 |

所有連線都有防護：快取、請求節流、每小時上限、被擋後自動停止連線一段時間。不管哪一種資料抓不到，畫面都不會中斷。

## 成本公式

日本實際台幣成本 = 日幣含稅價 ×（1 − 退稅%）× 匯率 ×（1 + 刷卡手續費%）

日本免稅的門檻和退稅方式，請以購買當下店家的規定為準。
