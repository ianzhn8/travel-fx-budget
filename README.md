# 👕 國際旅遊外幣購物預算精算機｜日系服飾版

比較日系大牌服飾在日本官網的價格，和同品牌在台灣蝦皮的價格。程式會把日幣標價換算成實際台幣成本（含刷卡手續費、退稅），再告訴你這件該在日本買，還是回台灣在蝦皮買。

## 執行

```bash
pip install -r requirements.txt
streamlit run app.py
```

如果在 Windows 上遇到應用程式控制原則封鎖，可以改成 `python -m pip …` 和 `python -m streamlit run app.py`，或是部署到 Streamlit Community Cloud。

## 支援品牌

| 品牌 | 日本價格來源 |
|---|---|
| UNIQLO、GU | 自動取得：日本官網的公開商品介面（迅銷集團的 commerce API），可以選擇商品，也可以選擇用定價或特價 |
| MUJI、Onitsuka Tiger、BEAMS | 手動輸入：這些品牌沒有公開介面，請到官網或門市確認含稅價 |

每個品牌都有預設的熱門品項，也可以選「自訂品項」。
- 日本官網要用**日文**關鍵字搜尋（例如 `ヒートテック`）。
- 蝦皮會自動用「品牌 + 中文品項」搜尋（例如 `UNIQLO HEATTECH 發熱衣`）。

## 資料處理

- **品牌過濾**：只保留標題含有品牌名的蝦皮商品。英文品牌名用單字邊界比對，所以 GU 不會誤配到 GUESS。「類 UNIQLO」「UNIQLO 風」這類仿款標題也會被排除。
- **極端值過濾**：用 IQR 法排除配件、福袋這類價格偏離的商品。
- **成本公式**：日本實際台幣成本 = 日幣含稅價 ×（1 − 退稅%）× 匯率 ×（1 + 刷卡手續費%）

## 防護機制

- **快取**：台銀匯率、日本官網、蝦皮的查詢結果都會快取 10 分鐘。
- **守門員**：每個網站各自控管請求。
  - 蝦皮：間隔 6 秒、每小時 20 次，被擋後冷卻 30 分鐘。
  - 日本官網：間隔 3 秒、每小時 40 次，被擋後冷卻 15 分鐘。
- **蝦皮資料來源有三種模式**：
  - 自動：先抓即時資料，失敗時改用備援資料。
  - 僅離線備援：完全不連蝦皮，錄影時推薦使用。
  - 匯入 JSON：用自己的瀏覽器在蝦皮搜尋，存下回應內容後上傳。
- **永不中斷**：任何連線失敗都只會在畫面上顯示原因，程式改用參考匯率、手動輸入的價格或離線備援資料繼續執行。

## 注意事項

- 蝦皮與日本官網的介面都不是公開文件，格式隨時可能改變。
- 不建議在雲端部署版填入蝦皮 Cookie，蝦皮可能判定為異常登入而鎖住帳號。
- 日本免稅的門檻和退稅方式請以購買當下店家的規定為準。
